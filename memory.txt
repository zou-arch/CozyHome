# 图片生成提示词规则

## 基础规则

### 1. 尺寸声明
- 明确指定图片尺寸（如 240x120, 120x60 等）
- 等距视角区块：240x120 像素
- 物体素材：根据实际需求设定

### 2. 纯色背景
- 使用纯色背景（与物品主色调对应）
- 方便后续抠图处理
- 背景色不能与物品颜色相近
- **重要：绿色植物不能用绿色背景，会混在一起无法抠图**
- 土生作物用棕色背景（与土壤相近，与绿色植物对比明显）

### 3. 像素风格
- 明确要求像素风格/像素画
- 可指定像素大小（如 16x16, 32x32 等）
- 保持清晰的像素边缘

### 4. 无阴影
- 不要添加阴影效果
- 阴影会干扰抠图
- 保持平面化设计

### 5. 多帧动画
- 需要上传参考图作为第一帧
- 描述动画变化规律
- 保持风格一致性

## 等距视角规则

### 地板样式
- 尺寸：240x120 像素
- 菱形形状（等距投影）
- 需要无缝拼接

### 种植区
- 尺寸：240x120 像素
- 土壤/土地质感
- 可添加农作物元素

## 物体素材规则

### 家具
- 尺寸：根据家具大小设定
- 需要正面和侧面视角
- 保持像素风格一致

### 作物
- 多阶段：种子→幼苗→成长→成熟
- 需要上传参考图
- 保持风格统一

### 宠物
- 多帧动画
- 需要上传参考图
- 保持动作连贯

## 示例提示词模板

```
像素风格，[物品描述]，等距视角，240x120像素，
纯色背景（[颜色]色），无阴影，清晰像素边缘，
适合2.5D游戏使用
```

## 种植区区块提示词

### 土生区块
```
像素风格，120x120像素菱形区块，
土壤/土地纹理，棕色系，
有小土堆和裂纹细节，
纯色对比背景(绿色 RGB: 0, 255, 0)，
无阴影，清晰像素边缘
```

### 水生区块
```
像素风格，120x120像素菱形区块，
水面/池塘纹理，蓝色系，
有波纹和睡莲叶细节，
纯色对比背景(橙色 RGB: 255, 165, 0)，
无阴影，清晰像素边缘
```

### 盆栽区块
```
像素风格，120x120像素菱形区块，
陶土/瓷砖地面纹理，陶土色系，
有瓷砖格子和花盆架细节，
纯色对比背景(青色 RGB: 0, 255, 255)，
无阴影，清晰像素边缘
```

### 沙生区块
```
像素风格，120x120像素菱形区块，
沙地/沙漠纹理，沙黄色系，
有沙粒和小石子细节，
纯色对比背景(紫色 RGB: 128, 0, 128)，
无阴影，清晰像素边缘
```

## 作物关键帧提示词

### 生长阶段
- 种子 (stage0)
- 幼苗 (stage1)
- 成长 (stage2)
- 成熟 (stage3)

### 土生作物 (32x32 像素, 绿色背景)

**番茄:**
- 种子: 棕色小颗粒
- 幼苗: 绿色小芽，两片叶子
- 成长: 绿色茎叶，有小花苞
- 成熟: 红色圆番茄，绿色蒂

**胡萝卜:**
- 种子: 细小棕色种子
- 幼苗: 羽状绿叶
- 成长: 茂盛绿叶，露出橙色顶部
- 成熟: 橙色胡萝卜，绿色叶子

**南瓜:**
- 种子: 扁平白色种子
- 幼苗: 心形绿叶，藤蔓
- 成长: 大叶子，黄色花朵
- 成熟: 橙色圆南瓜，绿色蒂

### 水生作物 (40x40 像素, 橙色背景)

**荷花:**
- 种子: 褐色圆种子
- 幼苗: 小圆绿叶浮在水面
- 成长: 大圆叶，粉色花苞
- 成熟: 粉色盛开荷花，绿色荷叶

**睡莲:**
- 种子: 黑色小种子
- 幼苗: 小圆叶浮在水面
- 成长: 圆形叶，白色花苞
- 成熟: 白色/粉色睡莲花，圆形叶

### 盆栽作物 (60x60 像素, 青色背景)

**多肉:**
- 种子: 细小种子在花盆中
- 幼苗: 小绿芽在花盆中
- 成长: 莲座状绿叶在花盆中
- 成熟: 饱满莲座状多肉在花盆中

**仙人掌:**
- 种子: 细小种子在花盆中
- 幼苗: 小绿球在花盆中
- 成长: 圆柱形仙人掌在花盆中
- 成熟: 高大仙人掌，有刺和花

### 沙生作物 (40x40 像素, 紫色背景)

**芦荟:**
- 种子: 细小种子
- 幼苗: 小绿芽，肉质叶片
- 成长: 莲座状肉质叶
- 成熟: 大芦荟，叶片饱满

**沙棘:**
- 种子: 细小种子
- 幼苗: 小绿芽，有刺
- 成长: 灌木状，有刺
- 成熟: 灌木，橙色果实

### 文件命名规则
- 种子: {crop_id}_stage0.png
- 幼苗: {crop_id}_stage1.png
- 成长: {crop_id}_stage2.png
- 成熟: {crop_id}_stage3.png
