# 种植区区块图片生成提示词

## 基础规则
- 尺寸：120x120 像素（用户视角为正方形）
- 像素风格
- 纯色对比背景（方便抠图）
- 无阴影
- 清晰像素边缘

---

## 1. 土生区块 (Soil)

**提示词：**
```
像素风格，120x120像素菱形区块，
土壤/土地纹理，棕色系，
有小土堆和裂纹细节，
纯色对比背景(绿色 RGB: 0, 255, 0)，
无阴影，清晰像素边缘
```

**参考描述：**
- 主色调：棕色 (139, 90, 43)
- 纹理：土壤、小土堆、裂纹
- 背景色：绿色（与棕色对比）

---

## 2. 水生区块 (Water)

**提示词：**
```
像素风格，120x120像素菱形区块，
水面/池塘纹理，蓝色系，
有波纹和睡莲叶细节，
纯色对比背景(橙色 RGB: 255, 165, 0)，
无阴影，清晰像素边缘
```

**参考描述：**
- 主色调：蓝色 (100, 150, 255)
- 纹理：水面波纹、睡莲叶、水草
- 背景色：橙色（与蓝色对比）

---

## 3. 盆栽区块 (Pot)

**提示词：**
```
像素风格，120x120像素菱形区块，
陶土/瓷砖地面纹理，陶土色系，
有瓷砖格子和花盆架细节，
纯色对比背景(青色 RGB: 0, 255, 255)，
无阴影，清晰像素边缘
```

**参考描述：**
- 主色调：陶土色 (200, 150, 100)
- 纹理：瓷砖格子、花盆架、陶土质感
- 背景色：青色（与陶土色对比）

---

## 4. 沙生区块 (Sand)

**提示词：**
```
像素风格，120x120像素菱形区块，
沙地/沙漠纹理，沙黄色系，
有沙粒和小石子细节，
纯色对比背景(紫色 RGB: 128, 0, 128)，
无阴影，清晰像素边缘
```

**参考描述：**
- 主色调：沙黄色 (240, 220, 160)
- 纹理：沙粒、小石子、干旱质感
- 背景色：紫色（与沙黄色对比）

---

## 生成顺序建议
1. 土生区块（最常用）
2. 水生区块
3. 盆栽区块
4. 沙生区块

## 后续扩展
- 可以添加更多细节（如水生区的鱼、土生区的蚯蚓等）
- 可以生成不同季节版本（春/夏/秋/冬）
