# 元宝校准指南

## 校准步骤

1. 打开腾讯元宝应用
2. 运行校准命令：
   ```bash
   python yuanbao_auto.py
   ```
3. 选择选项 1（校准按钮位置）
4. 按照提示依次将鼠标移动到以下位置：

### 需要校准的位置：

1. **发送按钮** - 输入框旁边的发送按钮位置
2. **图片位置** - 元宝生成图片的位置（用于右键下载）
3. **下载选项** - 右键菜单中的下载选项位置

### 校准技巧：

- 将鼠标精确移动到按钮中心
- 按 Enter 确认位置
- 校准完成后会保存到 yuanbao_coords.json

## 快速校准

如果不想运行交互式校准，可以手动创建 yuanbao_coords.json：

```json
{
  "发送按钮": [x, y],
  "图片位置": [x, y],
  "下载选项": [x, y]
}
```

## 测试校准

校准完成后，可以测试单个 Prompt：
```bash
python yuanbao_auto.py
```
选择选项 2（测试单个 Prompt）
